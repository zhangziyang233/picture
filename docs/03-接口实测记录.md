## 二、请求与响应结构

### 文字生图请求

```json
{
  "model": "agnes-image-2.1-flash",
  "prompt": "a red apple on a table",
  "size": "1K",
  "ratio": "1:1",
  "extra_body": { "response_format": "url" }
}
```

### 图片生图请求

```json
{
  "model": "agnes-image-2.1-flash",
  "prompt": "make it blue",
  "size": "1K",
  "ratio": "1:1",
  "extra_body": {
    "response_format": "url",
    "image": ["data:image/png;base64,<BASE64_DATA>"]
  }
}
```

### 成功响应

```json
{
  "data": [
    {
      "url": "https://<OUTPUT_HOST>/images/i2i/<TASK_ID>/output.png",
      "b64_json": "",
      "revised_prompt": ""
    }
  ],
  "created": 1790232652,
  "task_id": "<TASK_ID>"
}
```

文字生图与图片生图的响应结构一致，区别在于结果路径中的通道段：文字生图为 `t2i`，图片生图为 `i2i`。

## 三、用例与结果

### 3.1 生成能力

| 编号 | 场景 | 参数 | 结果 | 耗时 |
| --- | --- | --- | --- | --- |
| T1 | 文字生图 | 1K / 1:1 | 200 | — |
| T2 | 图片生图 | 64×64 PNG，`extra_body.image` | 200 | — |
| T3 | 图片生图 | 1024×1024 JPEG（0.76 MB） | 200 | 约 20 s |
| T4 | 图片生图 | 2048×1536 JPEG（2.69 MB） | 200 | 约 30 s |

| T6 | 工具命令行端到端 | 1K / 3:2，带参考图 | success | — |

### 3.2 参数位置敏感度

| 编号 | `image` 位置 | 结果 | 服务端返回 |
| --- | --- | --- | --- |
| P1 | `extra_body.image`（列表） | 200 | 正常，走 `i2i` 通道 |
| P2 | 顶层 `image`（列表） | 403 | `PermissionDeniedError: Model is blocked` |
| P3 | 顶层 `image`（字符串） | 403 | `PermissionDeniedError: Model is blocked` |

### 3.3 鉴权与校验

| 编号 | 用例 | 结果 |
| --- | --- | --- |
| A1 | 无效 Key 调用生图接口 | 401 `Invalid token (request id: <REQUEST_ID>)` |
| A2 | 有效 Key + 非法 `size` 调用生图接口 | 400 `size has invalid value "__invalid__"; must be one of: 1K, 2K, 3K, 4K, or WIDTHxHEIGHT` |
| A3 | `GET /v1/models` 传入无效字符串 | 多数返回 200，**鉴权不严格** |

## 四、关键发现

1. **`image` 必须放在 `extra_body` 内。** 放到顶层会被网关按对话请求处理，返回 403 `Model is blocked`。当前工具的写法是正确的，不要改动。

2. **`/v1/models` 不能用于校验 Key。** 实测对多个无效字符串仍返回 200，会产生「Key 有效」的误判。可靠且无成本的做法是调用生图接口并传入非法 `size`：401 表示 Key 无效，400 表示 Key 被接受。

3. **接口先校验鉴权、再校验参数。** 因此 A1 与 A2 的差异可以直接区分「Key 问题」与「参数问题」。

4. **参考图体积在 10 MB 上限内不影响成功率**，但会显著影响耗时（0.76 MB 约 20 s，6.71 MB 约 35 s）。

## 五、复现方式（已脱敏）

以下脚本仅用于验证 Key 有效性，不生成图片：

```python
import json, urllib.request, urllib.error

URL = "https://apihub.agnes-ai.com/v1/images/generations"
KEY = "sk-<YOUR_KEY>"   # 替换为你的 Key

body = {
    "model": "agnes-image-2.1-flash",
    "prompt": "key-check",
    "size": "__invalid__",   # 故意非法，避免真实生成
    "ratio": "1:1",
}
req = urllib.request.Request(
    URL,
    data=json.dumps(body).encode("utf-8"),
    headers={"Authorization": "Bearer " + KEY, "Content-Type": "application/json"},
)

try:
    with urllib.request.urlopen(req, timeout=45) as r:
        print("200 ->", r.status)
except urllib.error.HTTPError as e:
    print("HTTP", e.code, e.read(300).decode("utf-8", "replace"))
```

预期输出：

- `HTTP 401` → Key 无效
- `HTTP 400`（含 `size has invalid value`）→ Key 有效

> 工具已内置该逻辑，界面点「测试连接」即可，无需手动执行。
