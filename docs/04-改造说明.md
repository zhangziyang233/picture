# 改造说明

本次改动围绕两个目标：**让错误可读**、**让 Key 可配**。

## 一、`src/agnes_image.py`（核心模块 + CLI）

### 1.1 新增：个人 Key 存储

新增本目录下的 `api_config.json` 作为工具自有的凭据文件。

| 新增函数 | 说明 |
| --- | --- |
| `load_api_config()` | 读取工具自有配置，文件缺失时返回空配置 |
| `get_saved_api_key()` | 取已保存的 Key，复用现有的格式过滤逻辑 |
| `save_api_config(key, url=None)` | 校验后写入；采用临时文件 + 原子替换 |
| `clear_api_config()` | 删除配置，回退到环境变量或系统配置 |
| `mask_key(value)` | 掩码展示，前后各保留少量字符 |
| `active_credential()` | 返回当前实际生效的 Key、接口地址与来源标识 |
| `test_api_key(key=None, url=None, timeout=45)` | 无成本 Key 校验探针 |

### 1.2 修改：Key 取用优先级

`load_model()` 由「环境变量 → 系统模型配置」改为：

```
工具保存的 Key  →  环境变量 AGNES_API_KEY  →  系统模型配置中的 Agnes Key
```

未设置个人 Key 时行为与原来一致，不影响既有使用方式。

### 1.3 新增：服务端错误信息透出

新增 `_server_message()`，从 HTTPError 响应体中解析 `error.message`（截断至 300 字符并压缩空白），并在 `_http_error()` 中追加到提示末尾。

改动前：

```
HTTP 500：服务暂时异常，请稍后手动重试。
```

改动后：

```
HTTP 403：当前 Key 无权限使用该模型。 服务端返回：PermissionDeniedError: Model is blocked
```

`request_image()` 与 `download_item()` 两处的 `HTTPError` 捕获均已接入。

### 1.4 新增：命令行 Key 管理

| 参数 | 作用 |
| --- | --- |
| `--set-key KEY` | 保存或覆盖个人 Key |
| `--api-url URL` | 可选，配合 `--set-key` 指定自定义 HTTPS 接口地址 |
| `--clear-key` | 删除已保存的 Key |
| `--show-key` | 显示当前生效来源（掩码）与接口地址 |

## 二、`src/agnes_gui.pyw`（图形界面）

| 改动 | 说明 |

## 三、`src/启动生图工具.bat`（启动脚本）

原脚本内写死了本机专属的解释器路径，已改为通用探测：

1. 优先使用环境变量 `PYTHONW_EXE`；
2. 其次使用 `where pythonw` 的查询结果；
3. 再尝试用户目录下的常见安装位置；
4. 均未找到时给出明确提示并退出，不再硬编码任何具体路径。

原文件名 `生图工具.bat` 在仓库中更名为 `启动生图工具.bat`。
